# JoyQuest AI — Small Moments. Big Happiness.

**Theme:** Using Technology for Joy

An intentional wellbeing web application built with **Next.js 16** (App Router) and **Tailwind CSS v4** that transforms small positive actions into personalized, rewarding, and immersive experiences.

---

## ✨ Key Features

- **Multilingual Voice & Audio Dictation**: Real-time studio neural speech and ElevenLabs AI dictating mindful quests across 12 languages (English, Spanish, French, German, Italian, Portuguese, Hindi, Japanese, Korean, Chinese, Arabic, Polish) with native speaker personalities and on-the-fly translation.
- **Mood & Time Personalization**: Select from 8 moods and 4 time durations (2, 5, 10, 15 min).
- **Curated & AI Quests**: 48+ built-in fallback quests across 6 categories (Creativity, Movement, Kindness, Reflection, Nature, Social) plus Gemini AI generation with structured validation.
- **Interactive Quest Cards**: Checkable step-by-step progress, real-time timer ring, XP point awards, and celebratory confetti.
- **Virtual Joy Sanctuary**: A relaxing botanical grid where completed quests bloom and nurture new specimens.
- **Community Joy Wall**: Share joy notes and spread encouragement anonymously with like reactions.
- **Stats, Streaks & Achievements**: Level progression, active streaks, and category breakdowns.
- **Mindful 4-7-8 Breathing Orb**: Real-time guided breathwork overlay for instant calming.
- **Local Persistence & Privacy**: Safe client-side storage without intrusive tracking.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (Turbopack, App Router)
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design System with dark palette & glassmorphism
- **Typography**: Google Fonts (Outfit & Inter via `next/font/google`)
- **Voice / Audio**: Microsoft Studio Neural Voice & ElevenLabs Multilingual v2
- **Icons**: Lucide React & React Icons
- **Animations**: Framer Motion
- **AI Integration**: Google Gemini API (`gemini-2.0-flash`)
